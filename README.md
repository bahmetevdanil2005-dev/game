# ПУК-ПЛОТ: бегемот на реке

Браузерная 3D-игра на Three.js для подготовки к публикации в Яндекс Играх.

## Структура проекта

```
game/
├── index.html
├── README.md
└── moto_moto/
    ├── README.md
    └── textures/
        └── README.md
```

## Запуск

Откройте проект через локальный HTTP-сервер (не через `file://`), чтобы загрузчик GLTF мог прочитать модель.

## 3D-модель Moto Moto

Поместите файлы модели в папку `moto_moto/`:

- `scene.gltf`
- `scene.bin`
- `textures/` — все текстуры из исходного архива модели

Сохраняйте имена файлов и относительные пути, на которые ссылается `scene.gltf`. После загрузки модель будет доступна по пути `moto_moto/scene.gltf`, который ожидает игровой код.

## Яндекс Игры

В исходном коде предусмотрена необязательная загрузка SDK по пути `/sdk.js`. Перед публикацией подключите официальный SDK по актуальной инструкции Яндекс Игр и проверьте игру на HTTPS.
