# Пукающий бегемот — Fragment.Games

## Структура

- `index.html` — точка входа
- `assets/css/style.css` — стили заставки, меню и интерфейса
- `assets/js/main.js` — переходы экранов и модальные окна
- `assets/js/game.js` — игровой цикл, управление и физика (следующий этап)
- `assets/js/hippo.js` — модель и анимация бегемота (следующий этап)
- `assets/models/BegemotAnim.glb` — исходная 3D-модель пользователя

## Запуск

Проект опубликован через GitHub Pages. Открывать через HTTPS, чтобы браузер мог загрузить 3D-ресурсы.

## Этапы

1. Заставка студии и главное меню.
2. Подключение 3D-модели и камеры.
3. Анимация и управление бегемотом.
4. Игровой уровень, река, плот и эффекты.
