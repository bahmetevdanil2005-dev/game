# Модель Moto Moto

Сюда добавьте файлы модели с вашего устройства.

Ожидаемая структура:

```
moto_moto/
├── scene.gltf
├── scene.bin
└── textures/
    ├── texture_1.png
    └── ...
```

Названия текстур здесь приведены только как пример. Используйте реальные имена файлов из исходной модели и не меняйте относительные пути в `scene.gltf`.
